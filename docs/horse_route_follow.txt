HORSE ROUTE FOLLOW 1.1.2 - Kingdom Come: Deliverance II
by Flubbermunchkin

The game's horse auto-follow picks a branch at random at every fork. With this mod it follows
a route to your custom map marker instead: place a marker, get on a road, let the horse follow,
and it takes the right turn at every junction - like a GPS. The route is drawn on the map with
the same dotted line the game uses for fast travel, and the horse stops when you arrive.

This is one of our first mods for this game. It has been tested on one setup only, so expect
issues we have not run into yet - please report them (see BUG REPORTS below).

REQUIREMENTS
  - Kingdom Come Script Extender (KCSE) by JerryYOJ
      https://www.nexusmods.com/kingdomcomedeliverance2/mods/3332
  - Address Library For KCSE by JerryYOJ (required by KCSE itself)
      https://www.nexusmods.com/kingdomcomedeliverance2/mods/3381

INSTALL
  Vortex: install as usual.
  Manual: copy the "horse_route_follow" folder from this archive into <game>\Mods\
          (you should end up with <game>\Mods\horse_route_follow\KCSE\Plugins\kcd2_autotravel.dll).
  Uninstall: delete that folder.
  The mod's on-screen text (Localization folder) is only loaded if "horse_route_follow" is listed in
  <game>\Mods\mod_order.txt. Vortex takes care of that; with a manual install, add the line yourself
  if that file exists. Without it the mod still works, the "wrong way" notice just doesn't show.

HARDCORE MODE
  Hardcore does not allow custom map markers, so on its own the mod has nothing to route to there.
  The optional file "Hardcore Map Markers" (same Nexus page) allows custom markers in hardcore - on
  the map only, not on the compass - and the mod then works exactly as in a normal game.

HOW TO USE
  1. Open the map and place a custom marker. The planned route appears as a dotted line.
  2. Get on your horse, ride onto a road and let auto-follow take over as usual.
  3. The horse follows the route and stops on the road as close to the marker as it gets.
  The mod is always on (no hotkey). Remove the marker to ride with vanilla auto-follow.

HOW IT BEHAVES
  - The route is the shortest one by road. When you start off, the mod checks which way the
    horse faces: if you are heading away from the route, "Wrong way - turn around" is shown
    while you ride that way (the horse cannot turn around by itself). Turn around and the route
    continues; keep going and it is recalculated from where you are.
  - Once riding, the route is kept and only recalculated if you actually leave it (a wrong
    turn, a detour, pushed off the road by traffic).
  - The mod only chooses between roads the game's auto-follow offers. It never steers the horse
    itself, and it never leaves a moving horse without a road: if the game offers nothing that
    fits the route, the game's own choice wins and the route is recalculated.
  - The horse stops at the point of road closest to the marker (also for markers placed away
    from roads).
  - Some trails the game can auto-follow are not drawn on the map; routes may use them.

SETTINGS  (Mods\horse_route_follow\KCSE\Plugins\kcd2_autotravel.ini)
  [Options] BrakeOnArrival=1     briefly hold S to stop the horse on arrival (0 = don't)
            ArriveDistance=3     how many metres before that road point to stop
                                 (raise it if the horse overshoots, lower it if it stops short)
            UTurnPenalty=400     a later turn-around (dead end) counts as this many extra metres
            MapRoute=1           draw the route on the map (0 = don't)
            DebugLog=0           1 = detailed log for bug reports

KNOWN ISSUES AND LIMITATIONS
  - Only tested with the Steam version of the game (1.5.x, build 15693).
  - Regions: Trosecko is well tested; Kuttenberg and the monastery map are included but have had
    little testing.
  - Routes can sometimes take an odd detour even when a more direct main road exists. This is a
    known bug in how the mod reads the game's road network; the route is still valid and gets you
    there. A fix is planned.
  - The horse cannot turn around by itself: when you start off facing away from the route you
    are told to turn around (see HOW IT BEHAVES).
  - Only roads the game can auto-follow are used, so routes can differ from what the map shows,
    and a marker far from any road is reached only as far as the nearest road point.
  - At a road that simply ends, the horse stops; turn around and it continues.
  - In towns with many small streets the route can occasionally take a detour before it settles;
    it still gets there.
  - Other traffic (wagons, NPCs) blocks the horse the same way it does in vanilla.
  - The map line is drawn when the map updates the marker. Hovering a fast-travel point shows the
    game's own line in its place; the route comes back when the pointer leaves the point.
  - Stopping works by briefly holding S; it is skipped if another program has focus.
  - Mods that change horse auto-follow ("road magnetism") or the map screen may not be compatible.

GAME UPDATES
  The mod does not use fixed memory addresses. At startup it finds the game code it needs by
  pattern and by class name. If a game update changes that code, the mod turns itself off and
  changes nothing - the game simply plays as vanilla, it does not crash. The log then says
  "disabled: this game version is not supported yet". Watch this page for an update.
  (A game update that changes the road network itself would also need new road data.)

BUG REPORTS
  Please include kcd2_autotravel.log (next to the DLL, rewritten every session), ideally with
  DebugLog=1 set in the .ini, and say where you were riding to and from.

CHANGES
  1.1.2  - Fixed being routed to the wrong place when the map holds an extra, invisible marker:
           the route now follows the marker you placed or moved last (moving your marker used to
           change nothing, and the mod went idle after reaching the wrong spot).
         - Fixed Henry being pulled back towards the horse after dismounting near the destination:
           the arrival brake (holding S) now only happens on horseback.
  1.1.1  - The "Wrong way - turn around" notice no longer appears on foot (it now also requires
           that the horse is on auto-follow).
         - The notice works again when another mod hooks the same game function first (it was
           switched off with "notices_off" in the log).
  1.1.0  - Orientation check: starting off facing away from the route shows "Wrong way - turn
           around" (only while actually riding the road the wrong way) and keeps the route,
           instead of quietly planning a detour ahead.
         - Optional file "Hardcore Map Markers": custom map markers in hardcore mode (map only,
           not the compass), so the mod works there too.
  1.0.2  - No more on/off hotkey: the mod is always active (an accidental F6 press - or another
           mod using F6 - could silently switch it off).
         - The horse now stops at the point of road closest to the marker, also on long straight
           roads without junctions (it could ride past the marker there).
         - Fixed the first route of a session sometimes being planned on the wrong region's roads
           until the mod was toggled.
         - The route is planned once and kept. It is only recalculated when you actually leave it
           (more than 15 m off the route), not every time the game's look-ahead strays from it.
