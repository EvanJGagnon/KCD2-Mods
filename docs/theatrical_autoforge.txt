THEATRICAL AUTOFORGE 2.0.1-test - Kingdom Come: Deliverance II
PRIVATE RELEASE CANDIDATE - public release pending approval
by Flubbermunchkin

Henry forges the piece himself, stroke by stroke, while you watch. The mod plays the
blacksmithing minigame through the game's own forge actions: it heats the piece zone by zone
with the bellows, keeps the fire below the point where the metal burns, carries it to the anvil,
hammers in time with the forge music, turns the piece over about halfway (and again if one side
is worked out), reheats when it cools, and hands it over for the quench. Nothing is skipped or
completed instantly.

This is one of our first mods for this game. It has been tested on one setup only, so expect
issues we have not run into yet - please report them (see BUG REPORTS below).

REQUIREMENTS
  - Kingdom Come Script Extender (KCSE) by JerryYOJ
      https://www.nexusmods.com/kingdomcomedeliverance2/mods/3332
  - Address Library For KCSE by JerryYOJ (required by KCSE itself)
      https://www.nexusmods.com/kingdomcomedeliverance2/mods/3381

INSTALL
  Vortex: install as usual.
  Manual: copy the "theatrical_autoforge" folder from this archive into <game>\Mods\
          (you should end up with <game>\Mods\theatrical_autoforge\KCSE\Plugins\kcd2_autoforge.dll).
  Uninstall: delete that folder.

MULTI-RECIPE QUEUE (enabled in this candidate's supplied INI)
  On the game's forge recipe page, select each recipe and use + / - to set its
  amount. Numpad + / - also work. Delete clears the queue. The page shows queue
  material totals; additions are refused when the whole queue cannot be supplied.
  Press F9 once to start. The game checks and crafts each recipe normally.
  Between pieces the native result remains readable briefly, then closes through
  its own handler. The current player forge component is reacquired before the
  next native forge start: retired forge pointers are never reused.
  F9 pauses automation; unexpected states pause safely. Resume from the recipe
  page. Queue=0 restores single-piece operation. Do not replace DLLs while the
  game is running; back up existing configuration before installing.

HOW TO USE (single piece)
  1. At a forge, choose a blueprint as usual and wait until Henry is standing at the forge
     (or at the anvil).
  2. Press F9. Press F9 again at any time to stop and take over by hand.
  3. When the piece is finished the game's own quench runs; check the result as usual.

SETTINGS  (Mods\theatrical_autoforge\KCSE\Plugins\kcd2_autoforge.ini)
  [Keys]    Forge=F9        start/stop key (F1-F12, a letter or digit, or a symbol key such as ])
  [Options] FlipAt=50       turn the piece over once at this % completion (0 = only when a side is
                            worked out, as in 1.0.0). The "NoFlip" download is the same mod
                            with FlipAt=0.
            Queue=1         multi-recipe queue (source fallback is 0)
            AutoContinue=1  reopen the forge between queued pieces
            QueueAutoDismissResult=1  close intermediate native result dialogs
            QueueNotices=1  HUD status using bundled localization keys
            DebugLog=0      1 = detailed log for bug reports

TESTED
  Sword, long sword, axe, mace and horseshoe, with results around 0.97-0.99 quality.
  Other items use the game's generic workpiece and should work, but are untested.

KNOWN ISSUES AND LIMITATIONS
  - Only tested with the Steam version of the game (1.5.x, build 15693).
  - Strokes are timed to the forge music tempo; if a stroke misses, the next few may score a bit
    lower until the rhythm is re-established (the same as when you forge by hand).
  - Stamina is left to recover on its own; with very low stamina a stroke may be skipped.
  - If you interrupt the forge (leave, open a menu, get attacked), the mod stops; start it again
    with F9 once Henry is back at the forge.
  - Mods that change the blacksmithing minigame itself may not be compatible.

GAME UPDATES
  The mod does not use fixed memory addresses. At startup it finds the game code it needs by
  pattern and by class name. If a game update changes that code, the mod turns itself off and
  changes nothing - the game simply plays as vanilla, it does not crash. The log then says
  "disabled: this game version is not supported yet". Watch this page for an update.

BUG REPORTS
  Please include kcd2_autoforge.log (next to the DLL, rewritten every session), ideally with
  DebugLog=1 set in the .ini, and say what you were forging.

CHANGES
  2.0.1-test - Multi-recipe queue; native result dismissal driven while the forge
               update is suspended; safe native forge-component reacquisition.
             - HUD notices use bundled localization, not literal SendInfoText.
             - In-game verified: two queues completed, 3 and 4 items (7 total),
               on Steam build 15693. Tested DLL SHA256:
               479f7d814efb6faeb5b54aa67e40b1fca94783193c23e795b13aa2eef14dfea3
             - Offline checks are separate from that gameplay evidence. Broader
               game versions, interruptions and non-default settings still need
               additional coverage. Candidate retains its actual test version.
  1.1.2  - Fixed: the last stroke sometimes did not finish the piece (completion showed 99.9%
           and the mod waited instead of striking once more).
         - Fixed: sparkless duds and weak strokes on axes after 1.1.0. Henry now strikes the
           least-worn point (a worn-out spot gives nothing), starts every trip to the anvil on
           fresh metal, and treats a turned-over piece as lying mirrored, so the new side starts
           on the spots that worked on the first. Fewer duds also means fewer trips to the fire.
         - New "NoFlip" download: the same mod with FlipAt=0.
  1.1.1  - The key setting now accepts symbol keys such as ] or [; a key value the mod
           does not understand is reported in the log instead of silently using the default.
  1.1.0  - Henry now turns the piece over about halfway through (setting FlipAt). Turning it
           breaks the hammering rhythm for a few strokes, so those strokes go to fresh spots on
           the new side, where they still count in full, so the flip costs little or no quality.
