DESCRIPTION (BBCode)
[size=4][b]Theatrical AutoFollow[/b][/size]

Henry can follow anyone. Normally the game only offers "Follow" for certain NPCs - the ones it marks as followable, such as a guide leading you somewhere. This mod makes the game treat every NPC as followable, the way its own developer switch "wh_player_FollowAlwaysCanFollow" describes it ("player can follow anyone as if they had followable NPC side effect").

Everything else is the game's own following: the same Follow prompt and key, Henry walking or running after the person at their pace, the same way of stopping. The game's other rules still apply (it does not offer Follow for everyone in every situation, such as the dead). The mod adds no pathfinding of its own, moves nobody, and changes nothing in quests or your save.

[b]How to use[/b]
[list=1]
[*]Walk up to a person, ideally one who is walking somewhere, and look at them.
[*]The game's "Follow" prompt appears, as it does for a guide. Use it.
[*]Henry follows them until you move or stop following.
[/list]
[b]][/b] switches follow-anyone off (vanilla behaviour) and on again.

[b]Settings[/b] ([i]Mods\theatrical_autofollow\KCSE\Plugins\kcd2_autofollow.ini[/i])
[list]
[*][b]Toggle=][/b]: on/off key (F1-F12, a letter or digit, or a symbol key such as ])
[*][b]Enabled=1[/b]: 1 = on when the game starts
[*][b]Notices=1[/b]: 1 = short message when the key switches it
[*][b]SetCvar=1[/b]: 1 = also set the game's own (unused) developer switch
[*][b]DebugDraw=0[/b]: 1 = also turn on the game's own follow debug drawing (for testing)
[*][b]DebugLog=0[/b]: 1 = detailed log for bug reports
[/list]

[b]Compatibility[/b]
Changes one check in memory only, nothing on disk or in your save; ] switches it back to the game's own behaviour. Another mod that patches the same follow check would conflict.

[b]Game updates[/b]
The mod uses no fixed memory addresses: it finds the game code it needs by pattern at startup. Built and checked for the Steam version 1.5.x (build 15693); other stores and versions are untested. If a game update changes that code, the mod switches itself off and changes nothing, and its log says so.

[b]Bug reports[/b]
Please set DebugLog=1 in the .ini, reproduce the problem and attach [i]kcd2_autofollow.log[/i] (next to the DLL, rewritten every session).
