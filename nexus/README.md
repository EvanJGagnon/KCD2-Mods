# Nexus Mods pages (copy-paste)

One file per new mod. Each has the fields of the Nexus "add mod" form in order: name, category, summary
(Nexus allows 350 characters), the description in BBCode (paste into the BBCode editor), the file entries,
the requirements and the changelog. Tick "This mod contains content created with AI tools" like the
existing pages, and use the same author name (Flubbermunchkin).
