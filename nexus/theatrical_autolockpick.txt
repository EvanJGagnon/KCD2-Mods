DESCRIPTION (BBCode)
[size=4][b]Theatrical AutoLockpick[/b][/size]

Henry picks the lock himself. Start picking a lock and press [b]F2[/b]: his hand moves the pick onto the pin, waits until it sits, holds the turn key and follows the pin round as the lock turns, all through the game's own pick and turn controls. Press [b]F2[/b] again at any time to take over.

[b]What stays real[/b]
[list]
[*]The game adds Henry's tremble (his Thievery skill, and mods such as half hand shaking) to every move.
[*]The game decides whether the pick sits on the pin, wears the pick while it is off the pin, and breaks it.
[*]Locks beyond Henry's skill stay hard: he lets go when the pick slips (the lock springs back) and tries again, up to MaxTries times, then hands the lock back to you.
[*]After a pick breaks he stops; press F2 again to go on with the next pick.
[/list]
Nothing is written to the lock, the picks, the inventory or the skill.

[b]Installation[/b]
[list]
[*][b]Vortex:[/b] install as usual.
[*][b]Manual:[/b] copy the [i]theatrical_autolockpick[/i] folder from the archive into [i]<game>\Mods\[/i]. You should end up with [i]<game>\Mods\theatrical_autolockpick\KCSE\Plugins\kcd2_autolockpick.dll[/i].
[*][b]Uninstall:[/b] delete that folder.

Only download our mods from Nexus Mods (Flubbermunchkin) or our GitHub. They never come with an installer or .exe.

[b]Settings[/b] ([i]Mods\theatrical_autolockpick\KCSE\Plugins\kcd2_autolockpick.ini[/i])
[list]
[*][b]Pick=F2[/b]: start / stop (F1-F12, a letter or digit, or a symbol key such as ])
[*][b]AutoStart=0[/b]: 1 = start by itself on every lock (never right after a pick breaks)
[*][b]MaxTries=6[/b]: tries per lock before handing it back
[*][b]DebugLog=0[/b]: 1 = detailed log for bug reports
[/list]

[b]Compatibility[/b]
Uses only the game's own controls, so mods that change lock difficulty or Henry's tremble apply as normal (played with The Master Lockpicker - Half Hand Shaking). A mod that removes or replaces the lockpicking minigame leaves this mod nothing to do.

[b]Game updates[/b]
The mod uses no fixed memory addresses: it finds the game code it needs by pattern at startup. Built and checked for the Steam version 1.5.x (build 15693); other stores and versions are untested. If a game update changes that code, the mod switches itself off and changes nothing, and its log says so.

[b]Bug reports[/b]
Please set DebugLog=1 in the .ini, reproduce the problem and attach [i]kcd2_autolockpick.log[/i] (next to the DLL, rewritten every session).
