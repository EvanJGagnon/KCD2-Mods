DESCRIPTION (BBCode)
[size=4][b]Theatrical AutoDice[/b][/size]

Henry plays his own turns at the dice table while you watch. After every throw he looks the dice over, sets aside the ones worth keeping one at a time, and then either throws the rest again or passes, with the same game actions you use (hold, score and throw again, pass).

The game throws the dice, with each die's own weights, scores them, calls busts and pays out; the mod never changes the dice, the scores or the money. [b]Henry can lose.[/b]

[b]How he decides[/b]
For each throw the mod weighs every way of setting dice aside against what the dice he would throw next are likely to roll (it knows the side weights of Henry's own dice, so a lucky die is worth keeping in play), how far he is from the target score, and how close the opponent is to winning. Far ahead he plays it safe; when the opponent is about to win he presses on.

[b]How to use[/b]
[list=1]
[*]Sit down to a game of dice as usual (choose your dice and badges, place the bet).
[*]Press [b]F3[/b]. From then on Henry plays each of his turns himself. Press F3 again at any time to play by hand.
[*]Badges are left to you: use one by hand whenever you like; Henry carries on afterwards.
[/list]

[b]Settings[/b] ([i]Mods\theatrical_autodice\KCSE\Plugins\kcd2_autodice.ini[/i])
[list]
[*][b]Play=F3[/b]: start / stop (F1-F12, a letter or digit, or a symbol key such as ])
[*][b]SpeedPercent=100[/b]: how fast Henry plays (50 = slow and deliberate, 200 = brisk)
[*][b]RiskPercent=100[/b]: above 100 he presses on more, below 100 he banks sooner
[*][b]DebugLog=0[/b]: 1 = detailed log for bug reports
[/list]

[b]Compatibility[/b]
Uses only the game's own dice actions. Badges that change scoring are scored by the game itself, but Henry's plan does not take them into account; a mod that changes the scoring rules can make his choices worse.

[b]Game updates[/b]
The mod uses no fixed memory addresses: it finds the game code it needs by pattern at startup. Built and checked for the Steam version 1.5.x (build 15693); other stores and versions are untested. If a game update changes that code, the mod switches itself off and changes nothing, and its log says so.

[b]Bug reports[/b]
Please set DebugLog=1 in the .ini, reproduce the problem and attach [i]kcd2_autodice.log[/i] (next to the DLL, rewritten every session).
